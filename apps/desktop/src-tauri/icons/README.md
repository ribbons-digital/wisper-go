# Wispergo Icons

- `icon.png` is the full-color app/Dock icon used by Tauri bundle configuration.
- `tray-template.png` is a small monochrome menu bar/tray template icon.

The tray icon is wired with `icon_as_template(true)` on macOS so the system tints it for light and dark menu bar appearances. Keep this asset simple, opaque, and monochrome on transparent background.
